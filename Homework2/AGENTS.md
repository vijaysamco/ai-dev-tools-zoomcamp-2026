# AGENTS.md

## Project Context
This folder contains a small project for an expense splitter application.

## Instructions
- Keep the implementation simple and readable.
- Prefer a minimal MVP over extra features.
- Use Python with uv for the backend.
- Use Node.js for the frontend.
- Keep the app focused on shared expenses, member management, and balance calculation.

## Working Rules
- Update the documentation when behavior changes.
- Keep backend and frontend independent but compatible.
- Store any project notes under the `_docs` folder if needed.
- Favor straightforward logic over complex abstractions.

## Expected Outcome
A basic app that can:
- add members
- add expenses
- calculate balances
- show a list of expenses in a simple UI
